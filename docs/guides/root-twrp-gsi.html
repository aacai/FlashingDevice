📱 玩机终极指南：Magisk 隐藏 Root · TWRP · GSI 通刷

适用：已解 BL 锁的骁龙 / 天玑 / 三星 / Pixel 等设备 · Android 10～15

三大部分：① 装面具并藏好 Root → ② 刷 TWRP → ③ TWRP 卡刷 GSI，每一步都有命令和下载链接。

2026 现状：想把 Root 藏得最干净，主流已从"官方 Magisk"转向内核级方案（KernelSU / APatch），本指南三条路线全覆盖，按机型自选。

⚠️ 先看：解锁会清空数据！电量 > 60%，重要资料先备份。刷机有风险，变砖自负。

第零步：前置准备

0.1 解 Bootloader 锁（必须，否则一切免谈）

  • 小米/红米：绑定账号 → 开发者选项 → Mi 解锁状态 → 关机按住音量-进 Fastboot → 电脑跑官方 MiFlashUnlock（需等待 7 天）。
  • 一加 / Pixel / 摩托罗拉 / Nothing：开发者选项开 OEM 解锁 → adb reboot bootloader → fastboot flashing unlock，音量键确认。
  • 三星：开发者选项开 OEM 解锁 → Download 模式长按音量+ 解锁（部分美版/韩版无此选项，直接放弃）。
  • 华为（麒麟 980 后新机）：官方已关解锁通道，基本无解，跳过本指南。
❌ 解锁 = 恢复出厂设置，数据全灭。微信聊天记录、照片先备份到电脑！

第一部分：安装 Magisk（面具）拿 Root

原理Magisk 不动 system 分区，只打补丁到 boot（或 init_boot）镜像，OTA 相对友好，模块可随时开关。

1.1 下载官方 Magisk

  • Magisk 官方：github.com/topjohnwu/Magisk → Releases 下 Magisk-vXX.apk（直接装到手机上就行，APK 即安装器）。
  • 官方文档：topjohnwu.github.io/Magisk/install.html
⚠️ 别用搜索引擎里的"面具官网"山寨站（带下载器/收费的都是假的）。认准上面这个 GitHub 地址。狐狸面具 Kitsune（Magisk Delta）原作者已删库跑路，网上全是第三方镜像包，有投毒风险——新手只用官方版。

1.2 方法 A：打补丁 boot（最通用，推荐）

  1. 从线刷包里解出本机同版本的 boot.img（Android 13+ 且有 init_boot 分区的机型就取 init_boot.img）。
  2. 把 img 传到手机，打开 Magisk → 安装 → 选择并修补文件 → 选中它 → 得到 Download/magisk_patched_xxx.img 传回电脑。
  3. 手机进 Fastboot，电脑执行： 
    # 先确认槽位（A/B 机型刷当前槽）
fastboot getvar current-slot
# 刷入（boot 机型）
fastboot flash boot magisk_patched_xxx.img
# init_boot 机型则：
fastboot flash init_boot magisk_patched_xxx.img
fastboot reboot
  4. 开机打开 Magisk 显示版本号 + 已安装 即成功；提示"需要额外设置"点确定重启一次。

1.3 方法 B：TWRP 直刷（已有第三方 Recovery 时最省事）

把 Magisk-vXX.apk 后缀改成 .zip，TWRP 里 Install 选中刷入，重启即可。升级 Magisk 也是同理，或 App 内直接安装。

1.4 三星专属

Magisk 修补 AP_xxx.tar.md5 包里的 boot.img.lz4（或 init_boot），生成 patched tar，与 BL/CP/CSC 一起用 Odin 刷入（AP 槽选 patched 包）。三星刷完首次开机必须联网、且 Knox 熔断不可逆（支付/保修永久影响），想清楚再动手。

✅ 避坑：boot/init_boot 版本必须和当前系统版本一致；A/B 机型不要 cross 刷槽；刷完卡第一屏超过 10 分钟 → 进 Fastboot 刷回原版 img 即复活。

第一部分-B：内核级 Root（KernelSU / APatch，隐藏能力最强）

为什么更能藏：Magisk 在用户态有守护进程和挂载痕迹可查；KernelSU/APatch 把 su 做进内核，默认不对 App 暴露任何痕迹，只有你授权的应用才看得见 Root——这就是"专用隐藏"的本质，不用再跟各种检测斗智斗勇。

方案适合谁要求下载
KernelSU Next（最推荐）GKI 机型（近 3 年新机基本都是），想省心+隐藏拉满内核 5.10+ 可直接刷官方 GKI 内核；4.19~5.4 需找带驱动的第三方内核KernelSU-Next（Releases 下管理器 APK + 内核）
SukiSU Ultra要 KPM 内核模块、susfs 深度隐藏的玩家同上，GKI 最省事SukiSU-Ultra
APatch老内核（3.18+）/ 非 GKI 机型，不想换整个内核arm64，需内核开 CONFIG_KALLSYMS；自己设一个高强度 SuperKeybmax121/APatch（只认 Releases 的 APK）

KernelSU 系安装（GKI 机型，5 分钟）

  1. 下载对应内核版本（如 android12-5.10）的 Image.gz/boot 镜像，或用管理器自带的刷机方式。
  2. fastboot flash boot xxx.img（或按发布页说明刷 init_boot），重启装管理器 APK。
  3. 管理器 → 模块装 ZygiskNext 或 ReZygisk（二选一）→ 重启 → 再装 Shamiko / Zygisk Assistant，隐藏配置和第二部分完全一样。
  4. 终极隐藏再加 SUSFS 模块（susfs4ksu，需内核支持），连挂载痕迹一起抹掉。

APatch 安装

  1. 安装 APK → 设置一个又长又随机的 SuperKey（这就是你的 Root 密码，丢了/弱了等于裸奔）。
  2. App 内修补 boot → 得到 patched 镜像 → fastboot flash boot 刷入 → 重启。
  3. 管理器里把银行/游戏加进排除列表（Exclude），再装 ZygiskNext + Shamiko，后面和第二部分一样。
⚠️ 选型建议：GKI 新机无脑 KernelSU Next；老机器/冷门机查不到 KSU 内核就 APatch； Magisk 生态模块最多，玩 Xposed 花活多的人可以 Magisk 为主 + 这一节的隐藏模块补强。三星 Knox 机三条路都会熔断，自己掂量。

第二部分：隐藏 Root（银行 / 支付 / 游戏检测全过）

现代检测 = 三层：su 文件/包名 → Zygisk 注入痕迹 → Play Integrity（硬件级）。按下面顺序一套配下来，绝大多数 App 全绿。

2.1 第一步：把 Magisk App 自己藏起来

Magisk 设置 → 隐藏 Magisk 应用 → 取个普通名字（如"设置服务"）→ 确定。原理：检测软件会扫包名 com.topjohnwu.magisk，改名即隐身。

2.2 第二步：Zygisk + 排除列表（DenyList）

  1. Magisk 设置 → 打开 Zygisk → 重启。
  2. 设置 → 配置排除列表 → 勾上银行/支付/游戏/政务 App（把"显示系统应用"打开，连带勾 com.google.android.gms.unstable 不要勾，那是完整性检测进程，勾了反而失败）。
  3. 关键：遵守排除列表（Enforce DenyList）保持关闭（开了就和 Shamiko 冲突）。

2.3 第三步：Shamiko（核心隐藏模块）

  • 下载：github.com/LSPosed/LSPosed.github.io/releases（LSPosed 团队官方发布页，取最新版 zip）。
  • Magisk → 模块 → 从本地安装 → 重启。Shamiko 会读取上面的排除列表自动隐藏，要求就是 2.2 那条：Enforce 保持关闭。

2.4 第四步：过 Play Integrity（装 Xposed 模块前先搞定）

方案效果下载
PlayIntegrityFork（推荐新手）过 BASIC + DEVICE，可用钱包/门禁/RCSgithub.com/osm0sis/PlayIntegrityFork（模块内 Action 点一下自动抓指纹）
TrickyStore（进阶，最强）配合未封禁 keybox 可冲 STRONG，银行最稳github.com/5ec1cff/TrickyStore（keybox 需自备有效文件放 /data/adb/tricky_store/keybox.xml）
ZygiskNext（可选替换）替代官方 Zygisk 加载方式，过部分 ptrace 检测github.com/Dr-TSNG/ZygiskNext（装它就要关 Magisk 自带 Zygisk）
ReZygisk（开源替代）ZygiskNext 的全开源复刻，KSU/APatch 必备二选一github.com/PerformanC/ReZygisk（XDA 实测对付顽固银行 App 有奇效）
Zygisk Assistant（专用隐藏）轻量隐藏 root+Zygisk 痕迹，Magisk/KSU/APatch 通用github.com/snake-4/Zygisk-Assistant（和 Shamiko 二选一或叠加，别和 Enforce DenyList 同开）
⚠️ PIFork + TrickyStore 二选一即可，别叠着装。TrickyStore 1.1.0 起闭源，按 README 来；keybox 网上公开的基本都被谷歌封了，DEVICE 能过就行，别死磕 STRONG。

2.5 第五步：Hide My AppList（防"应用列表"检测）

  • 有些 App 扫你装了 Magisk/MT管理器/冰箱就判 root。装 LSPosed 框架（LSPosed 存档版 / 活跃继任 Vector（原 LSPosed_mod）），再装模块 Hide My AppList：github.com/Dr-TSNG/Hide-My-Applist。
  • 用法：新建黑名单模板 → 勾"所有应用对这些 App 不可见" → 作用域只勾需要隐藏的 App → 在 HMA 自带测试里验证全绿。

2.6 自查三件套（按顺序测）

  1. Root Checker / Momo：确认 su 正常、Momo 无痕迹。
  2. Play 商店 → 设置 → Play 保护机制认证：显示"已认证设备"。
  3. 银行/游戏实测：还弹 root 警告就回头检查：排除列表漏勾？Enforce 误开了？GMS 被勾了？模块装多了（字体模块最容易露馅，先全关再一个个开）。

第四部分：刷入 TWRP Recovery

4.1 找对包

  • 官网机型库：twrp.me/Devices → 搜 codename → 下 .img。没你机型就去 XDA/酷安找第三方适配，或用 OrangeFox（orangefox.download，对 A/B 和加密 Data 支持更好）。
  • 包名里 boot 版是一体包（刷到 boot 分区），recovery 版刷 recovery 分区——按发布页说明来，别搞混。

4.2 fastboot 刷入

# 有独立 recovery 分区的老机型
fastboot flash recovery twrp-xxx.img
fastboot reboot recovery        # 直接进，别先进系统（部分系统会回写官方recovery）

# A/B 机型（无 recovery 分区，twrp 做进 boot）
fastboot boot twrp-xxx.img      # 先临时启动，进 TWRP 后再 Advanced → Install Recovery Ramdisk 永久化
# 或
fastboot flash boot twrp-xxx.img
⚠️ 进 TWRP 问要不要"保持 system 只读"：只是看看选只读；要刷机/Root 选允许修改。Data 解不开密（输密码报错）→ 说明 TWRP 不支持你这版加密，先 Format Data（会清空！）或换 OrangeFox 新版。

4.3 进 TWRP 第一件事：备份

Backup → 勾 boot + super（或 system）+ persist + efs/modemst（有就勾，丢了=没信号没 IMEI）→ 存到电脑一份。这是你所有折腾的后悔药。

第五部分：用 TWRP 刷 GSI 通用系统

GSI Treble 机型通用的半成品系统镜像（一包刷所有 Treble 机），适合体验原生/AOSP。先用 Treble Info 确认：Project Treble: Yes，记下 A/B 还是 A-only、arm64 / VNDK 版本。

5.1 下载 GSI（PHH 大神版最稳）

  • PHH Treble：github.com/phhusson/treble_experimentations → Releases，按 Treble Info 的架构下： system-td-arm64-ab-vanilla.img.xz（无 GMS 原生）或 gapps 版（带谷歌全家桶，小白直接拿 gapps 版）。
  • 文件名 ab 对 A/B 机，a64/a-only 对老机，别下错。
  • 解压得到 system-xxx.img 传到手机 /sdcard。

5.2 关验证（AVB），否则 GSI 开机红字/卡死

# 电脑 fastboot 下执行（vbmeta 分区刷空验证标记）
fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img
# vbmeta.img 从本机线刷包里取；部分机型还要同步刷 vbmeta_system：
fastboot --disable-verity --disable-verification flash vbmeta_system vbmeta_system.img

5.3 TWRP 里开刷（以 A/B 机为例）

  1. Wipe → Format Data 输入 yes（从 MIUI/ColorOS 等转 GSI 必须格 Data）。
  2. Install → 右下 Install Image → 选中 system-xxx.img → 分区选 System Image → 滑动刷入。
  3. （可选）同方式刷 vbmeta 空验证，或回电脑执行 5.2。
  4. Reboot → System，首次开机 5～10 分钟，耐心等。

5.4 开机后三件事

  • 没信号/没指纹？PHH 自带 treble settings（phh 设置）→ 按机型开 IMS / 指纹 / 亮度修复；酷安搜机型+GSI 有现成补丁。
  • 要 Root？GSI 下直接 TWRP 卡刷 Magisk apk 改的 zip（见 1.3），或 fastboot boot 进 TWRP 刷。
  • 想回官方？Fastboot 线刷回原厂包即可（所以 0.2 的线刷包是底牌）。
✅ GSI 省流组合：PHH gapps 版 + Magisk（Direct Install）+ 本指南第二部分的隐藏四件套 = 主力机可用的原生系统。

救砖 & FAQ

  • 刷完 Magisk 卡第一屏：Fastboot 刷回原版 boot/init_boot，90% 复活。
  • 装模块变砖（无限重启）：① TWRP → Advanced → 文件管理删 /data/adb/modules/问题模块；② 没 TWRP 就 adb wait-for-device shell magisk --remove-modules（ fastboot 进带 adb 的安全模式下执行）。
  • 真砖（fastboot 都没了）：高通机 9008 线刷——正好用我们这个 FlashingDevice 项目救。
  • 银行 App 还是过不了？检查顺序：Magisk 改名了没 → 排除列表勾了没（GMS unstable 别勾）→ Enforce 关了没 → Shamiko/PIFork 版本是不是最新 → 用 HMA 把 MT/冰箱藏了没 → 换 TrickyStore。
  • GSI 没信号：phh 设置开 IMS + 确认刷的是对应 AB 类型的包 + 基带（modem）别乱动。
  • OTA 升级后 Root 没了：正常。OTA 前 Magisk 里"卸载→还原原厂镜像"，OTA 后重走 1.2（A/B 机可 OTA 到副槽后 Magisk"安装到未使用的槽位"实现无缝）。
